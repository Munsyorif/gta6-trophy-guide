Leonida Trophy Guide is an offline GTA 6 trophy guide and tracker for all 55 PlayStation 5 trophies — every official name, description and grade, a roadmap to the platinum, missable flags, and a cited guide for each trophy. Its checklist saves progress in the browser, with filters by kind, a spoiler mode that hides story trophies until earned, and export/import. Dark PlayStation theme, works with the network off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
